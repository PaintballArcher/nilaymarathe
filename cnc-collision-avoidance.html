Overview

This project explored path planning and collision avoidance for machining processes in a modeled CNC environment. I developed an interactive 3-DOF CNC station and represented its links, joints, and coordinate frames in URDF.

Point-cloud data of the workspace was created using SLAM to support collision avoidance with and without obstacles.

01 / CONTRIBUTIONS

What I worked on

  • Implemented machining path-planning strategies in ROS with MoveIt! and RViz.
  • Created point-cloud workspace data for obstacle-aware planning.
  • Modeled the CNC station in Fusion 360 and described it using URDF.
