# Nilay Marathe portfolio

Static portfolio files for GitHub Pages. The site uses black, white, grayscale, and a restrained brass accent. All type uses DM Sans. The four supplied project screenshots appear on the home page and their matching project pages.

## Upload

Upload the files in this directory to the root of a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

`index.html` is the home page. Each project has a separate HTML page. `styles.css` controls the shared design. `NilayMarathe_Resume.pdf` is the public résumé download, and `.nojekyll` keeps GitHub Pages from applying Jekyll processing.

## Project pages

- `multi-robot-construction.html`
- `battery-disassembly.html`
- `citysimrl.html`
- `manipulator-path-planning.html`
- `cnc-collision-avoidance.html`
- `philosophy-rag-chatbot.html`

Each page has a “Case study details” placeholder for your future figures and narrative. Projects without supplied screenshots also have a clearly labeled image placeholder. Edit the HTML directly to replace those sections.

The supplied screenshots are saved as `construction-planning.png`, `citysimrl.png`, `battery-disassembly.png`, and `manipulator-path-planning.png`. Keep these files beside the HTML pages when uploading. Projects without supplied screenshots retain illustration placeholders.
