Overview

This research compared Model Predictive Path Integral (MPPI) planning against SIMULINK's built-in inverse kinematics planner for a 4-DOF manipulator with a paintbrush end effector.

I also demonstrated constrained 2D end-effector motion for a PincherX100 robot arm in ROS and SIMULINK.

01 / CONTRIBUTIONS

What I worked on

  • Examined the efficiency of MPPI and inverse kinematics approaches for a paintbrush end effector.
  • Demonstrated constrained 2D motion for the PincherX100 robot arm.
  • Compared planner performance in the project setting.
02 / RESULT

Planner comparison

In this evaluation, SIMULINK's built-in planner path was reported as 12 ± 2.4% faster than the MPPI algorithm.
